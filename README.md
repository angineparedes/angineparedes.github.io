# Sitio de servicios digitales

Sitio estático, adaptable a móvil, preparado para GitHub Pages. No necesita dependencias ni servicios de pago.

## Personalización

1. Abre `index.html`.
2. Busca `const WHATSAPP_NUMBER = '';` cerca del final.
3. Agrega tu número internacional **solo con dígitos**, sin `+`, espacios ni guiones. Para México, comprueba que el número funcione en `wa.me` antes de publicar.
4. Si quieres, cambia `WHATSAPP_MESSAGE`, el título y los textos.
5. Abre `index.html` en tu navegador para ver la página.

## Publicar en GitHub Pages

1. Crea un repositorio público nuevo en GitHub.
2. Sube `index.html` a la raíz de la rama `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. GitHub mostrará la dirección pública cuando se complete la publicación.

No requiere tarjeta bancaria. El sitio no incluye formularios ni almacena datos personales. El botón WhatsApp solo redirige cuando se configura el número.
